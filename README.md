# MathGame
Console based application where user can answer math questions.   
Created using C#/.Net 10

## Features
- Console based UI


  - <img width="452" height="254" alt="image" src="https://github.com/user-attachments/assets/dc091af6-f029-4486-ac71-330311c1ca51" />

- Five different "game modes"
  - Addition
  - Subtraction
  - Division
  - Multiplication
  - Random
    - All above modes mixed

- Difficulty setting
  - Easy
  - Hard

- Score and timer for each individual game

  - <img width="362" height="87" alt="image" src="https://github.com/user-attachments/assets/c3ba2ccb-0e01-4e06-a2eb-cd7716f6b9f2" />

- Viewable game history with statistics
